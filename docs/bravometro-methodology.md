# Metodología Bravómetro 1.0

La nota global es una media ponderada, limitada a 0–10 y redondeada a una decimal:

| Atributo | Peso |
|---|---:|
| Salsa | 24% |
| Patata | 20% |
| Sabor | 20% |
| Picante | 10% |
| Textura | 10% |
| Calidad/precio | 9% |
| Cantidad | 7% |

La confianza combina volumen de evidencias (hasta 75 puntos) y diversidad de fuentes (hasta 25). Etiquetas: inicial `<42`, media `42–71`, alta `≥72`. Toda valoración conserva `methodologyVersion`; una futura fórmula no reescribe resultados históricos.
