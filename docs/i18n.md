# Internacionalización

Las URLs incluyen locale: `/es` y `/en`. Los diccionarios centralizados están en `src/lib/i18n.ts`; `es` es el idioma por defecto. Las páginas declaran canonical y alternates. Para añadir un idioma se amplía `Locale`, `locales`, el diccionario y las traducciones editoriales.

Las valoraciones mantienen resúmenes separados por idioma. Si falta una traducción futura, la capa de datos deberá devolver español como fallback.
