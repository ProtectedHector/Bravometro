# SEO

El proyecto incluye metadata global y por ficha, Open Graph, iconos, canonical/hreflang, JSON-LD, sitemap y robots. `/es/mejores-bravas-madrid` y `/en/best-patatas-bravas-madrid` redirigen al ranking hasta disponer de contenido editorial suficiente.

Antes de producción configura `NEXT_PUBLIC_SITE_URL`, sustituye datos demo y revisa que solo perfiles publicados entren en sitemap.
